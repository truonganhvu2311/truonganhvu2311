## Featured Data Engineering Project

### E-commerce Sales & Weather Analytics Pipeline

Built an end-to-end ELT pipeline integrating e-commerce transactional data with historical weather information to support business analytics.

**Key Highlights:**

- Implemented Python-based incremental extraction using timestamps, watermarks, and soft deletes.
- Integrated PostgreSQL transactions and Open-Meteo historical weather data.
- Stored raw data in Google Cloud Storage and processed it in BigQuery.
- Organized analytical datasets into Raw, Staging, Intermediate, and Mart layers.
- Developed 11 dbt models and validated 87 successful model/test executions in a documented run.
- Orchestrated incremental transactional processing using Apache Airflow and Docker.
- Implemented data quality checks, idempotency controls, and QA-gated watermark updates.
- Created three Looker Studio dashboard pages for sales, products, and weather-related analysis.

**Technologies:** Python, PostgreSQL, GCS, BigQuery, dbt, Apache Airflow, Docker, Looker Studio
